This policy explains what data Mashrou3i Publisher (“the tool”) accesses, how it is used, stored and deleted. The tool is operated by Prof. Fellah Mohamed for his own YouTube channel only.

1. Use of YouTube API Services

The tool uses YouTube API Services to upload videos and manage playlists and thumbnails on the operator's own channel. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (www.google.com/policies/privacy).

2. Data the tool accesses

  • OAuth credentials of the channel owner's Google account, granted through Google's consent screen with the scopes youtube.upload and youtube.
  • Video metadata the tool creates: the IDs of the videos and playlists it uploads or creates.

The tool does not access, collect or store any data about viewers, subscribers, comments, analytics, or any other user or channel.

3. How data is used

The credentials are used only to upload the operator's own lesson videos, set their thumbnails and add them to his playlists. Video IDs are used only to let the «مشروعي» classroom app play these videos through the standard YouTube embedded player.

4. Storage and security

  • The OAuth refresh token is stored only as an encrypted GitHub Actions secret in the operator's repository. It is never written to files, logs or any third-party service.
  • Video IDs are stored in a registry file (youtube/videos.json) in the operator's repository.
  • No cookies, tracking or analytics are used by this website or the tool.

5. Sharing

The tool does not sell, share or transfer any data to third parties. Data is exchanged only with Google/YouTube through the YouTube API Services.

6. Revoking access and deleting data

  • Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions.
  • Deleting the GitHub secret YT_REFRESH_TOKEN removes the stored credential immediately.
  • Upon revocation, or on request, any stored authorization data is deleted within 7 days, and API data is not kept for longer than 30 days unless it is refreshed.

7. Changes

Any change to this policy will be published on this page with a new “last updated” date.
